# Life Happens

Life Happens is a private, single-user macOS application for viewing personal wellness data in one
place. It can connect to the account owner's Oura account to display sleep, readiness, activity,
heart-rate, blood-oxygen, stress, resilience, and heart-health information.

The application runs locally on the owner's Mac. Oura data is requested only after the owner
authorizes access and explicitly starts a synchronization. Life Happens does not sell health data,
use it for advertising, or send directly imported Oura data to an artificial-intelligence model.

## Oura connection

Life Happens uses Oura's OAuth authorization process. The owner is redirected to Oura to review and
approve the requested permissions; the owner's Oura password is never entered into Life Happens.
OAuth credentials are stored in macOS Keychain, while imported measurements are stored locally on
the Mac.

The owner can disconnect Oura without deleting measurements already imported into Life Happens, or
can separately delete all imported Oura data from the application.

## Important notice

Life Happens is a personal wellness dashboard. It is not a medical device and does not provide
medical advice, diagnosis, or treatment. Questions about health or symptoms should be discussed
with a qualified healthcare professional.
